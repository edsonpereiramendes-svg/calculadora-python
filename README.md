# 🧮 Calculadora em Python

Calculadora desenvolvida em Python com duas versões: uma de **terminal** e uma com **interface gráfica** (usando Tkinter). O projeto inclui operações matemáticas básicas, potência, raiz quadrada e tratamento de erros.

## 📋 Funcionalidades

- Operações básicas: soma (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`)
- Potência (`**`)
- Resto da divisão / módulo (`%`)
- Divisão inteira (`//`)
- Tratamento de erros: divisão por zero, valores inválidos e números grandes demais (Overflow)
- Loop para fazer várias contas sem reiniciar o programa (versão terminal)
- Interface gráfica com botões clicáveis (versão Tkinter)

## 🗂️ Arquivos do projeto

| Arquivo | Descrição |
|---------|-----------|
| `calculadora.py` | Versão de terminal, com loop para múltiplas operações |
| `calculadora_grafica.py` | Versão com interface gráfica usando Tkinter |

## ▶️ Como executar

Você precisa ter o **Python 3** instalado. O Tkinter já vem por padrão.

**Versão terminal:**
bash
python calculadora.py


Versão gráfica:

bash
python calculadora_grafica.py
```

🧠 Conceitos praticados

· Variáveis e tipos de dados (float, str)
· Estruturas condicionais (if / elif / else)
· Tratamento de exceções (try / except com ValueError, ZeroDivisionError, OverflowError)
· Funções (def, return, raise)
· Laços de repetição (while True, break)
· Módulos da biblioteca padrão (math)
· Interface gráfica com Tkinter (tk.Entry, tk.Button, grid)
